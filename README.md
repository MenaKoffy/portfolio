# Mena Koffy — Cyberpunk Comic Portfolio

A responsive GitHub Pages portfolio starter built around a cyberpunk comic-book visual identity.

## Files
- `index.html` — page structure
- `style.css` — visual design and responsive layout
- `script.js` — cursor glow, navigation state, reveal animations
- `assets/hero.png` — generated hero artwork

## GitHub Pages
Upload these files to the `portfolio` repository, then enable GitHub Pages from:
**Settings → Pages → Deploy from a branch → `main` → `/ (root)`**.

Replace the placeholder project blocks with your real work and change `your@email.com` in `index.html` to your contact email.
